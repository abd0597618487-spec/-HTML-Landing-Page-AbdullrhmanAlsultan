# Mountain Landing Page

## Project description
This project is a simple, responsive landing page built with HTML and CSS.
It uses the supplied black-and-white mountain photograph as the hero background.

## Project files
- `index.html` — contains the page structure and the CSS styles.
- `assets/landing.jpg` — the background image used in the hero section.

## Main parts of the code
1. **HTML head:** defines the page language, character encoding, viewport, and browser-tab title.
2. **CSS styles:** control the page layout, navigation, typography, background image, button, and mobile layout.
3. **Header:** contains the website logo and navigation links.
4. **Hero section:** displays the main heading, description, and call-to-action link over the mountain image.
5. **Footer:** displays the copyright note.
6. **Responsive media query:** adjusts the layout for smaller screens.

## How to run the project
1. Download or clone this repository.
2. Keep `index.html` and the `assets` folder in the same project directory.
3. Open `index.html` in a web browser.

## Technologies used
- HTML5
- CSS3
